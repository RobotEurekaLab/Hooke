# Attributed space assets

These third-party assets retain their own terms, independently of Hooke's code
license. Read each asset's `NOTICE.md` before reuse. `manifest.json` records the
original repository, pinned commit, source hashes, terms, credits, exported file
hashes and conversion scope. `scenes.json` records Hooke's optional scene variants.

- ISS laboratory and handrail: NASA Media Usage Guidelines.
- Apollo sample: CC0, as identified by Space Robotics Bench's attribution list.
- Mars 2020 tube: original NASA/JPL-Caltech resource under NASA media guidelines;
  Space Robotics Bench modifications under CC0.

Geometry and diffuse textures are converted for research simulation. Physical
properties, collision proxies and installation fixtures are illustrative Hooke
settings, not measured NASA specimen or certified spacecraft hardware data.

See [reuse and validation](../../../docs/space_asset_reuse.md) from the repository
root documentation. NASA/JPL endorsement is not implied.
