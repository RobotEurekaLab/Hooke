# Isaac 实际性能与测量范围

完整移液专家的优化前后记录来自同一任务、种子和机械输入。16,819 步控制、位置、速度、时间和接触数组逐字段及类型完全相等，实际耗时从 466.580 秒降到 456.531 秒，改善约 2.2%。这是单个完整专家回合的比较，不代表全目录平均加速。[完整结果与证据哈希](validation/isaac_full_expert_performance_comparison.json)。

## 原生步进分析

`comprehensive_profile_baseline` 实际执行 150 个原生步进。总壁钟 1.436 秒，cProfile 测量段 1.419 秒：

| 调用 | 累计耗时 | 占测量段比例 | 范围 |
| --- | ---: | ---: | --- |
| `World.step` | 1.183 秒 | 83.4% | 包含物理推进和同步接触事件回调 |
| `_contact_report` | 0.383 秒 | 27.0% | 已包含在上一行，不能再次相加 |
| `observe` | 0.163 秒 | 11.5% | 原生关节、刚体位姿和源坐标映射 |

运行器的 `physics_wall_s` 包含步进阶段的控制更新、原生推进和接触回调，不是纯 PhysX 内核计时。客户端 socket 接收累计时间也包含等待 worker 计算，不能全部解释为通信开销。该小段分析没有覆盖完整 IK/轨迹规划、文件记录或渲染。

## 同步格式

500 步原生 JSON 与二进制同步诊断的完整观测语义哈希相等。壁钟为 9.017 和 6.342 秒，包含 worker 计算及其波动，约 1.42 倍；它不能外推为完整专家加速。二进制通道使用私有 socket、长度上限和权限限制，JSON 通道保留用于诊断。

优化保留每个接触点和原生积分，批量读取刚体位姿、缓存不变坐标关系，并用向量操作检查接触集合。没有降低碰撞精度、删除接触或用 MuJoCo 替代 PhysX。

## 仍存在的性能差距

复杂 SDF/螺纹接触的完整任务仍明显慢于 MuJoCo。改变圆柱碰撞近似会改变物理行为，历史诊断未通过原操作判定，因此未作为默认加速。线程诊断亦未证明增加线程可显著改善这类场景。

本轮未取得实时性能等价性。新增十种子报告按后端、模式分别记录实际耗时和仿真时长；不同负载、冻结版本、显示配置与机器之间不直接推算加速。
