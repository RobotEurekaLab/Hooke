# 显微实验平台目标验收

2026-09-18。本次自动目标的 demo 范围已完成：可合法复用的真实电动微操 CAD、独立参考倒置镜、空心针与电动夹爪、贴壁和双侧吸持注射、MuJoCo／原生 Isaac、实际网页与录像。下列结果对应当前 `parallel-v4` 模型，不沿用旧装配的检查结论。

## 查看与运行

[打开当前 Isaac 显微实验室](http://10.5.174.93:8084/microscopy?experiment=suction_injection&backend=isaac)。选择实验并点击“运行实验”，或手动控制器械、载物台、调焦和压力；环境选择器可以切换 MuJoCo。页面提供全景、仪器近景、细胞／物镜／采集光路视角及实验录像。

当前服务采用 `reference` 资产、`te2000-s-reference` 镜体、参考载物台、`estimated` 光学和 `parallel-v4` 微操机构。它无需用途许可未确认的厂商 CAD。固定来源、准备和完整启动命令见[并联机构](microscopy_parallel.md)；其他服务账号的 Isaac 安装配置见[部署说明](isaac_operations.md)。仅访问这台服务器网页的用户共用服务器配置。

## 尺度、反馈与装配指标

- 贴壁目标 36 × 28 × 8 µm，悬浮目标直径 36 µm；三维显示增益为 1。
- 注射针与水平夹角 35°，吸持管 30°；空心针尖外径 1.2 µm、内径 0.5 µm。当前归档原生模型的针口网格独立测量通过；三维、合成轮廓与流阻共用 SI 参数。
- 原生正常五条流程记录 **57,481 个实际 PhysX 步及独立事件、210 张原始世界 RGB**。十项原生故障对照另有 16,800 步，主服务冷启动另核对 150 步；均未由 MuJoCo 重放替代。
- 两后端各五条当前完整运动的表面间距检查通过、零跳过。双针总成检查 823 件表面，三工具总成 947 件；检查计入平移、旋转及 100 µm 几何容差，仅覆盖观察到的动作与声明区域。
- 原生求解原点移至平台附近，归档与界面仍使用源世界坐标。细胞动作采用真实步进的 50 ms 反馈窗口：平均残差 ≤50 nm、各轴 RMS 抖动 ≤0.3 µm、峰值偏离均值 ≤0.8 µm。
- 当前正常细胞流程的十三次原生动作均满足上述条件，最多两次校正；其中最大平均残差约 45 nm、RMS 抖动约 249 nm、峰值约 643 nm、末次瞬时残差约 418 nm。**平均残差不能解释为瞬时精度或实机精度**；细胞模型始终读取每步实际位置。

## 模型边界

镜体是独立尺寸／照片参考重建，没有官方整机 CAD 或经核验的整机一比一主张。支撑、针座适配、工具伸出、质量、惯量、控制增益、重力补偿、夹爪外壳和承载仍含估算；杆上的橡皮筋网格不模拟弹性预紧。

PhysX 执行器械刚体动力学与接触；细胞、膜响应、吸持和流量为未生物标定的降阶模型，显微视野为合成成像。尚未验证实机纳米精度、存活率、膜修复、真实光学、FEM／CFD、完整厂商行程、同总成所有内部配合或加工承载。这些是公开的使用边界，不能由流程通过推导为科学准确性。

当前安装与权限已在本机服务账号核验。另一台机器或另一 Linux 账号启动 Hooke，需要配置其可访问的 Isaac 安装；未经访问的远程 `/home/dongsu/...` 环境不列为已修复。
