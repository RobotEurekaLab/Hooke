# Universe 太空实验场景与资产

本阶段只建设空间站、月球和火星的实验工作区、共用资产与环境声明。E1/E2 仪器校准、Scientist Agent 和正式科学评测另行实现。场景通过短时刚体与出图检查，不代表完整太空环境或科学实验通过。

网页入口 `/space-worlds` 展示三个场景的环境分区、真实双引擎图片、资产及限制；链接到 `/backends?task=...` 可打开对应场景。本机使用 GPU 6 和原有 535.230.02 驱动。

## 三种环境

| 场景 | 工作区重力 | 工作区参考气压 | 实验场景与防护 |
| --- | ---: | ---: | --- |
| 空间站实验舱 | 局部共同自由落体近似，0 m/s² | 101,325 Pa | 固定实验架、抓握扶手、固定机械臂、样品保持架；舱内空气和舱外真空分别记录 |
| 月球表面 | 1.62 m/s² | 理想真空近似，0 Pa | 地面锚固的干样品工作台、封闭实验模块参考外观、程序化岩石；暴露样品必须审查密封需求 |
| 火星表面 | 3.73 m/s²，采用平均表面重力 | 636 Pa，参考条件 | 干样品工作台、封闭模块参考外观、程序化岩石；记录稀薄 CO₂ 大气，气流与尘埃未模拟 |

空间站近失重来自共同自由落体，模型采用随站运动的局部坐标系。地球对轨道中的站体仍有引力；本模型忽略轨道梯度、姿态变化、残余加速度和固定机器人引起的站体反冲。[NASA 微重力说明](https://www.nasa.gov/centers-and-facilities/glenn/what-is-microgravity/)

实验舱参考值选用类似 ISS 的气压。NASA 给出的名义 ISS 舱内条件包括约 14.7 psi 气压和 17–28°C 气温；本例选用 293.15 K。舱体使用剖开前壁与顶棚的布局方便相机观察，该几何不代表气密舱体。[NASA ISS 环境资料](https://www.nasa.gov/wp-content/uploads/2023/08/np-2022-06-009-jsc-iss-tech-demo-mini-book-proof-3.pdf)

月球存在极稀薄外逸层；0 Pa 是本例刚体实验的理想真空近似。1.62 m/s² 和 1,361 W/m² 太阳辐照参考 NASA。热辐射边界选用 250 K，是声明的场景设置；日照、纬度与遮阴会造成不同温度，不能将它解释成统一的月球空气或地表温度。[NASA 月球参数表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/moonfact.html)

火星的 3.73 m/s²、636 Pa、以 CO₂ 为主的组成和 586.2 W/m² 太阳辐照参考 NASA。气压随地点和季节改变。214 K 在本例仅作为简化热辐射边界，其辐射有效温度未经现场数据标定，也不表示所有物体温度都为此值。[NASA 火星参数表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/marsfact.html)

## 环境机制的实际范围

| 机制 | 本阶段状态 | 实验影响与边界 |
| --- | --- | --- |
| 重力、刚体质量与惯量 | 两引擎实际配置和步进 | 同一 0.1 kg 未固定干样品进行漂浮／下落检查；不通过降低质量伪造低重力 |
| 碰撞与固定安装 | 原模型及程序化几何 | 机械臂、实验台、仪器和存放样品显式固定；样品夹具操作与抓取尚未验收 |
| 气压与环境分区 | 参考条件和设计检查 | 舱内、舱外、封闭模块目标分开记录；未实现气体流动、压差载荷、泄漏或抽气 |
| 热辐射 | 按实际 episode 时间更新的简化见证模型 | 预设太阳吸收和灰体热辐射；无遮挡射线、视角因子、结构传导或材料反馈 |
| 气流、对流与浮力 | 禁用 | 空间站舱内和火星有气体；禁用这些机制不能解释为它们实际不存在 |
| 尘埃、静电和颗粒地面 | 尚未模拟 | 岩石是静态凸网格，地面是固定平面；未验证松散月壤、沉陷、扬尘或吸附 |
| 液体相变与挥发 | 尚未模拟 | 干样品为默认范围；湿实验即使采用密封外观仍需相态与密封资格验证 |
| 粒子辐射、紫外损伤、老化与放气 | 尚未模拟 | 不将材质颜色、辐照字段或热辐射模型当作损伤/寿命模型 |

真空中不能沿用气体对流散热，但仍存在热辐射及结构接触传导。空间站舱外辐射边界的 3 K 是理想深空参考，当前见证模型使用工作区边界；近地轨道的地球红外、反照和日食未在本模型实现。[NASA 热交换说明](https://cosmicopia.gsfc.nasa.gov/qa_sp_ht.html)

月尘的磨蚀、静电吸附与污染是设备和密封设计的重要因素。当前资产提供后续防护与清洁接口的设计起点，未声称具备防尘性能。[NASA 月尘与设备资料](https://science.nasa.gov/science-research/science-enabling-technology/technology-highlights/new-moon-duster-will-help-clean-nasa-assets-in-space/)

## 共用实验资产

| 资产 | 来源与尺度 | 可用范围 |
| --- | --- | --- |
| UR5e 与原夹爪 | 复用仓库原机器人、视觉网格、关节和执行器 | 固定基座显示及短时运行；新重力域中的抓取与装样需要单独验证 |
| 工作面与实验台 | 空间站采用舱壁连接的固定面板和支架；月球/火星用原 `simple_table.xml` | 空间站无落地桌腿，仪器与存放样品依靠连接件固定，不靠重量或桌面摩擦 |
| 密封样品盒原型 | 新程序化资产，壳体直径 48 mm、高 70 mm，带盖和抓握环；总质量 0.1 kg | 干样品容器概念；气密性、开盖、内部样品物性与材料兼容性未验收 |
| 三位样品保持架 | 新底板与夹持外观，三个样品显式固定 | 近失重存放参考；固定安装不代表机器人已成功锁定夹具 |
| 称量模块 | 月球/火星用原分析天平外观；空间站移除普通重力天平 | 不支持失重称量；当地重力校准、支撑反力与质量估计尚未接入 |
| 单轴惯性滑台原型 | 新导轨、0.2 kg 托盘、±90 mm 行程、5 N/m 弹簧、0.1 N·s/m 阻尼 | 真实单轴关节；测量、参考加载与校准属于后续 E1 工作 |
| 样品隔离模块 | 原 glovebox 外观及可动前窗 | 几何参考；不是已验证的真空兼容或承压舱 |
| 封闭实验模块参考 | 月球/火星场景中的舱体和舱门外观 | 101,325 Pa、293.15 K 是内部设计目标，未实现气体密封或主动温控 |
| 舱内机架、扶手、地面锚固与岩石 | 新程序化几何，统一米制、Z-up | 不是实际 ISS 数字孪生、实测月面或火星地形 |

新岩石把非均匀形状直接写入凸网格顶点，避免将非均匀缩放球体误当成 PhysX 等价碰撞形状。源文件、生成场景和复用资产的 SHA-256 保存于 [资产清单](../Hooke/worlds/assets_manifest.json)。原型保留原机器人文件；后续导入的四个外部模型只用于独立场景变体，见 [资产复用记录](space_asset_reuse.md)。

## 配置、生成与运行

[环境配置](../Hooke/worlds/profiles.py)、[资产生成器](../Hooke/worlds/build.py)、[环境系统](../Hooke/worlds/environment.py) 和 [目录适配](../Hooke/worlds/tasks.py) 分开组织。添加环境或仪器可复用这些接口，无需把场景规则塞进 Isaac worker。

从源码目录运行：

```bash
cd Hooke
../.venv/bin/python -m worlds.build
HOOKE_RENDER_FPS=2 HOOKE_ISAAC_COLOR_PIPELINE=source_display \
  ../.venv/bin/python -m worlds.qualify \
  --gpu 6 --output ../temp/backend_parity/space-worlds-validation
../.venv/bin/python -m backends.run --task space_lunar_workstation \
  --backend isaac --mode preview --seconds 2 --gpu 6 \
  --output ../temp/lunar-preview
```

新任务都是展示／物理检查入口，`check()` 返回 false，不输出科学实验成功。原 167 项目录证据保留历史范围；添加三个原型及三个资产变体后目录为 173 项，不将它们混成新全目录原生资格认证。

热见证模型采用示例热容 90 J/K、辐射面积 0.01 m²、太阳投影面积 0.001 m²、吸收率 0.3、发射率 0.8。模型只与实际仿真时间耦合；参数未经材料标定，也不改变刚体质量、膨胀或颜色。

`exposure_issues()` 对未固定的近失重样品、低压未密封样品和未验收湿实验报告设计问题。10 kPa 是保守的设计审查阈值，不是沸点、材料失效或气密性定律；声明 `sealed=True` 不能代替物理密封验证。

## 实际验收与后续资产工作

[短时场景结果](validation/space_worlds_summary.json) 保存三场景 × 两引擎的实际轨迹检查、物理时钟、图片与源资产对照。[结构检查](validation/space_worlds_preflight.json) 只表示三个新场景编译及原生启动前检查通过。

[附加地面接触检查](validation/space_worlds_ground_contact.json) 分别运行两引擎火星场景 2 秒、1,000 步，观察到未固定样品与地面接触、有限状态与合理的离地高度。它不验收默认设置的静止速度门限或长期稳定性。[局域网浏览器检查](validation/space_worlds_browser.json) 覆盖桌面和手机的三个世界、两个视角，验证 12 张在线图片的哈希和运行页面的场景链接。当前 133 项单元测试通过，日志哈希保留于短时场景报告。

漂浮／下落测试在 0.5 秒内保持测试物与地面、实验台分离，位置对连续解析解的公差为 2.5 mm，速度公差为 2 mm/s；位置允许 2 ms 时间步带来的积分误差，不代表全部接触精度。该测试不验收长时稳定性、夹具、软土、气密性或科学仪器。

首次原型的空间站全景存在侧壁遮挡，岩石采用非均匀椭球时出现 PhysX 碰撞表示警告。初始日志与图片保留在 `temp/backend_parity/space-worlds-v1/`；视角和岩石网格修正后重新运行，最新证据使用独立的 `space-worlds-v2/`。

后续资产优先补：可操作并经验证的样品保持机构、带反力采样的称量台、可加载与校准的惯性滑台、可识别密封状态的隔离模块，以及有来源和分辨率声明的月球/火星地形。环境损伤模型和大型场景扩展各自验收。

[开放场景与资产调研](space_asset_sources.md) 已核查 NASA Astrobee 舱内模型、SRB 实验资产、OmniLRS 月球场景、NASA/JPL 火星地形工具及数据来源，并记录当前 Isaac 4.5 的适配要求。四个外部模型已接入独立的 `/space-assets` 场景变体；本页仍展示程序化原型。空间站原型也已调整为舱壁固定工作面。

空间站安装修正后，已在 `space-worlds-orbital-v3/` 单独重新运行双引擎，更新工作面、移除普通重力天平和截图；月球/火星原型的历史场景未改动。
