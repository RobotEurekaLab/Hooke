# Isaac 分支完成度与验收指标

## 发布判断

当前适合发布为 **实验性功能分支**，继续开发和评审。当前目录的加载、真实物理运行、原控制器反馈和网页入口已打通；完整物理、视觉、性能及跨种子等价尚未验收。所有结果仍标记 `parity_qualified=false`。

不以一个主观百分比表示整体完成度。下面分别报告有明确分母的覆盖率和未完成的验收项。

## 最新流程回归

[完整双容器移液与共享任务判定](isaac_pipette_transfer.md) 记录新增 `pipette_transfer`、实际盖板及锁盖判定、柱塞端点容差和逐回合验证状态。当前目录共 166 项；下方 165 项全目录表为历史基线，未重新认证整个新目录。新完整移液的原生复测状态以新报告为准，离线重放不计为原生成功回合。

[双引擎共享控制与移液体积模型](isaac_shared_processes.md) 记录插管多种子扩展、30 秒内涡旋动作、实际活塞驱动的理想体积模型、独立液面几何验收及原生移液失败修正。原生默认涡旋完成一个种子，实际耗时 2397.459 秒，仍有明显性能差距；下方性能表保留历史回合。

## 视觉与性能

热混匀仪两边完整回合均更新屏幕纹理 21 次。实际腕部相机最终能读到 `0:30`、`33 / 25°C`、`600 RPM`。33°C 是设定温度，25°C 是原系统实际温度；没有实现或宣称该回合已升温至 33°C。

| 实测运行 | 仿真时长 | 实际耗时 | 端到端实时系数 |
| --- | ---: | ---: | ---: |
| HPLC，Isaac，网页带渲染 | 9.244 s | 73.641 s | 0.126× |
| 热混匀仪，MuJoCo，网页带渲染 | 16.188 s | 24.328 s | 0.665× |
| 热混匀仪，Isaac，网页带渲染 | 16.336 s | 121.767 s | 0.134× |
| 涡旋混匀仪，Isaac，不渲染 | 54.584 s | 4,234.349 s（70.6 分钟） | 0.0129× |

实时系数为“仿真秒 / 实际秒”，1× 才代表实时。这些耗时包括启动、控制器、跨进程通信、记录及相应渲染，不是纯物理步进基准。表中为先前配置的历史记录；默认 worker 改为 8 个 tasking 线程；后续共享配方的完整涡旋性能单独记录于上方流程报告。热混匀仪两个带渲染回合的实际耗时相差约 5 倍。复杂螺纹接触是当前明显的性能短板。

环境：现有 NVIDIA 535.230.02 驱动未修改；Isaac Sim 4.5、MuJoCo 3.3；使用独立空闲 GPU。结果来自本机，未证明其他机器、驱动或 Isaac 版本兼容。

## 未完成项与优先级

1. **跨种子与长稳测试**：原 22 项专家基线是 seed 0；新增选择性多种子回归与失败分类见 [回合判据说明](isaac_episode_assessment.md)。仍需扩展至全部交互任务与长稳测试。
2. **复杂接触性能与精度**：优化螺纹 SDF 求解，验收实际旋合；接触阻抗、非线性摩擦和柔顺约束仍有近似。
3. **源任务质量**：保留上述历史原判据基线，新增 v2 回合验收。移液器改为逐步记录实际动作顺序；通风柜要求接触与有效关窗位移；涡旋检查试管接触旋转平台。插入任务保留原公差并报告误差。控制器、科学过程模型仍需分别修复和验证。
4. **声明时限**：历史基线中，5430 关盖及其复合任务、通风柜虽原判据成功，但两边均超出原声明时限；涡旋源专家也超时。通风橱后续修复的时限结果见上方单项报告。
5. **视觉等价**：动态屏幕、贴图方向和液面已接入；光照、天空盒、玻璃和材质响应尚未匹配，未统计像素误差。
6. **科学模型**：复用源项目已有仪器逻辑；称量、热学、流体等完整科学模型并未因导入外观而自动实现。
7. **通用性与部署**：ball、柔性体、空间腱、未知插件、外部刚体 wrench 等仍有明确不支持路径。当前默认安装路径和 GPU 选择面向现有服务器，部署到其他机器需要配置。
